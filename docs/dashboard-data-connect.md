# 대시보드 화면 구조와 데이터 연결 가이드 (2026-10-22)

이번 작업은 **화면(UI)만** 만들었습니다. 구글시트·Apps Script·공개 집계 API·자동 동기화·KPI 계산식·고객관리카드·이카운트·잔디 추출 파일은 수정하지 않았습니다.
(변경 파일: `src/dashboard-ui.js`(신규) · `src/dashboard-ui.css`(신규) · `src/kpi-sheet-page.js` · `src/kpi-sheet-page.css` · 빌드 결과 `index.html`. 데이터 연결 모듈 `sheet-source.js` · `growth-core.js` · `public-pack.js` · `growth-page.js`는 이전 배포본과 동일.)

## 1. 화면 구성
| 위치 | 내용 | 데이터 상태 |
|---|---|---|
| 메뉴 ① 대시보드 | 핵심 KPI 3 → 현황 요약 4(업체·L2·L3·공고·낙찰·메인자재) → 추이·흐름(월별 추이, L2→L3 흐름, L2→L3→L4 / L2→L4 / L3→L4 경로 비교) → 추가 데이터 5종 입구 → 팀 행동 이력 | KPI ③·현황 요약·L2→L3 흐름은 기존 시트 값, 나머지는 '데이터 연결 예정' |
| 메뉴 ② 성장 분석 | 기존 화면 그대로 | 기존 연결 유지 |
| 메뉴 ③ 데이터 | 추가 데이터 5종 상세 화면(영업보고 L2 · 협약일 · L3 자료 · 이카운트 매출 · 행동 이력) | 매출은 연도별 3개 값만 일부 연결, 나머지 '데이터 연결 예정' |
| 상세 보기(로그인) 모드 | 기존 메뉴 전부 유지(요약(근거 목록)·매출·원문·낙찰·시공사·영업활동·선행지표·연결 설정) | 기존 그대로 |

KPI 3개 카드(신규 업체 사용률 · 재사용률 · L2 → L3 전환률)는 한 곳(`dashboard-ui.js`의 `kpiCard`)에서만 만들며 중복 카드가 없습니다. 각 카드: 지표명 · 현재 수치 · 정의 · 전년 대비 · 추이 · 상세 보기(해당 데이터 화면으로 이동).
- 전년 대비는 전년 표본(L2 건수)이 30건 이상일 때만 `▲/▼ %p`로 표시하고, 아니면 '비교 불가'(상수 `MIN_SAMPLE`, 표시 기준일 뿐 계산식이 아님).
- 추이는 값이 2개 이상일 때만 선을 그리고, 아니면 '추이 — 연결 예정'.

## 3. 데이터가 들어오면 수정할 파일과 위치
화면을 다시 만들 필요 없이 **어댑터 한 곳만** 연결합니다.

1. 공개 집계에 값이 실리면(서버 쪽 집계 추가는 별도 지시): `src/dashboard-ui.js` 맨 아래(또는 별도 스크립트)에서
   `B2BDashUI.connect("l2" | "mou" | "l3" | "sales" | "act", function (api, filters) { return { … }; })` 로 연결.
   반환 형식은 `dashboard-ui.js` 머리 주석에 있음: `status`("connected"|"partial") · `asOf` · `source`(원본 출처) · `stats` · `monthly` · `breakdowns` · `rows`(+ `verify`: "ok"|"review").
2. 화면 정의(통계 항목·표 열·중복 키)는 `dashboard-ui.js`의 `DATASETS` 한 곳. 열/통계 이름을 바꾸려면 여기만 수정.
3. 메인 대시보드의 KPI 카드 값은 `render()` 안 `kpiCard` 호출부 3곳(`ok`·`value`·`yoy`·`trend`)에서 어댑터 값으로 바꾸면 됨.
4. 이미 연결된 값을 쓰는 '일부 연결' 처리는 `builtin()` 함수(지금은 이카운트 매출만).
5. 색상·간격 등 디자인은 `src/dashboard-ui.css` 한 곳.

## 4. 중복 집계 방지·검증 상태 설계
- 각 데이터 화면에 중복 키가 정의되어 있음(`DATASETS[*].dedupe`): 예) 영업보고 = 영업보고일+업체+아파트, L3 = 활동일+업체+아파트+유형, 협약일 = B2B 고유코드, 매출 = 매출일+업체+품목+금액.
- 같은 키가 두 번 들어오면 두 번째 행을 '중복 의심'(붉은 줄)으로 표시하고 확인 건수에서 제외.
- 각 행에는 검증 상태 칩(확인 완료 · 검증 필요 · 미검증 · 중복 의심)이 붙고, 목록 위에 상태별 건수가 표시됨.
- 시험: 가상 TEST 데이터를 로컬 화면에서만 주입해 연결 구조·중복 표시·필터·월별 막대·순위 목록을 확인했고, 배포 파일에는 가상 데이터가 없음.
