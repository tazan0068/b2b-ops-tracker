## 2. 전년 대비·월별 추이
- **전년 대비**: `—`/`검증 필요`는 코드 고정 문자열이었습니다(`dashboard-ui.js` KPI 카드 생성부). 같은 정의의 전년 값이 없어 숫자를 만들지 않고 "비교 데이터 부족"과 이유를 표시하도록 바꿨습니다. 원인: 플랫폼 L3 채널(기술자문·컨설팅요청·발행이력·설명회·기타)은 2026년 1~2분기부터 시작해 2025년과 측정 범위가 다르고, 분석 시작일 이전 L3는 집계하지 않아 협약일부터의 관측이 왼쪽으로 잘립니다. 업체·현장 확정 L3: 2025Q3 75 → 2026Q3 721.
- **월별**: L3·공고·낙찰 월별은 원래 연결돼 있었고, KPI 카드의 "추이 — 월별 집계 연결 후 표시"는 고정 문구였습니다. 신규 업체 사용률·재사용률 월별(월말 기준, 마지막 달 = 메인 카드 분자·분모)과 메인자재 구매 월별(업체 수·순매출)을 집계 생성기에 추가하고 카드 추이·월별 블록에 연결했습니다. **2025-06은 막대·라벨·설명에 6/24~30 부분 기간으로 표시**했습니다. 2026-01 이전 KPI 월별은 플랫폼 기록 편입 전이라 낮게 나올 수 있음을 함께 표시합니다. L2 영업보고 월별은 원천이 없어 표시하지 않습니다.
- 새 집계 행은 시트 반영 전입니다(승인 후 붙여넣기). 반영 전에는 이전 표시로 안전하게 돌아갑니다.

## 3. 경로별 전환률
- L2 영업보고 원천이 0행이라 **L2→L3→L4, L2→L4는 계산하지 않았습니다**(0이 아니라 "구분 불가"). 모든 L3는 "L2 미기록"이며 "직접 진입 확정"으로 단정하지 않습니다.
- 참고(경로 미확정 L3 → L4, 업체 확인·현장 연결 확정 L3의 업체×현장×공종 조합 1,386, 첫 L3 후 365일, 자사 공고·POUR 낙찰): 공고 도달 223(16.1%), 낙찰 도달 193(13.9%, 같은 업체 낙찰 101=7.3%). 경로 분석 7종의 "L3 → L4" 칸에 분자·분모와 함께 "검증 전·경로 미확정"으로 표시.
- 연결 근거: 업체는 통합ID(B2B코드·사업자번호 대조 결과 반영), 현장은 현장ID, 공종은 공종그룹, 날짜는 L3 이후 공고일. 이름만 같은 연결은 확정하지 않음. L3보다 앞선 공고만 있는 조합은 도달에서 제외.

## 6. 자동 동기화·접근 권한
- 영업활동(②)만 실시간 기록(서버 `sheetsSync`). ②·③→① 통합 시트 자동 반영, 카드 협약일 자동 반영, 이카운트·잔디 자동 적재는 **현재 없음**(수동 가져오기·1회 적재, 자동화 초안·시험만 있음). 로컬 pipeline은 멱등(키+해시), 운영 ①에는 중복·누락 방지 장치와 동기화 로그가 없음. 공개 JSON `meta.sourceModified`는 변경을 처음 관측한 시각이며 원천 반영일이 아님.
- 공개 응답 점검: 사업자번호·전화·이메일·시트ID·B2B코드·ENT-ID·URL·업체 접미어 패턴 0건. 공개 URL의 doPost 없음(읽기 전용 배포 버전 1).
- 접근: ①·시험 수신함은 익명 차단. **②(링크 편집자)·③(링크 열람)은 로그인 없이 읽힘**(업체·현장 상세 포함) — 사용자가 유지 결정했으나 위험으로 보고. 공개 보기/Google 로그인 상세 보기 구분은 실제로 동작, 트래커 내 열람 역할 개념은 없음.
- 승인 필요: ②·③ 공유 범위 축소, ②·③→① 자동 동기화 설치, 운영 Apps Script 새 버전(협약일 동기화 코드 분리 후).
