# B2B 업무 트래커 + 통합 KPI 대시보드

단일 HTML 파일로 동작하는 팀 업무 트래커에 통합 KPI 첫 화면을 넣은 프로그램입니다. **이 저장소에는 회사 데이터가 들어 있지 않습니다.** 실제 수치는 비공개 Google 스프레드시트에서 읽기 전용 Apps Script 웹앱을 통해 불러오며, 연결 전에는 모든 지표가 "연결 대기"로 표시됩니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 트래커 + KPI 대시보드 (브라우저에서 바로 열기, 설치 불필요) |
| `apps-script/Code.gs` | 스프레드시트에 붙여 배포하는 읽기 전용 API (키 검증 · 호출 한도 · 허용 시트 목록) |
| `apps-script/README.md` | 배포 순서와 보안 모델 |
| `src/` | KPI 화면 모듈 소스 (`sheet-source.js` 데이터 소스 · `kpi-sheet-page.js` 화면 · `kpi-sheet-page.css` · 성장 분석: `growth-core.js` 계산 · `growth-page.js` 화면 · `growth-page.css`) |
| `tools/` | 로컬 테스트용 모의 API 서버 (Apps Script 응답 방식 시뮬레이터 포함) |

## 사용 순서 (권장: A. Google 로그인)

1. 스프레드시트 소유자가 열람할 직원 계정에 **뷰어**로 공유합니다. (시트는 비공개 유지, 공유 해제 = 열람 회수)
2. 관리자가 Google Cloud 콘솔에서 프로젝트 생성 → **Google Sheets API** 사용 설정 → OAuth 동의 화면 → 사용자 인증 정보 → **OAuth 클라이언트 ID(웹 애플리케이션)**, 승인된 JavaScript 원본에 사이트 주소(예: https://<계정>.github.io)를 등록합니다. (클라이언트 ID는 비밀이 아닙니다)
3. 직원은 `index.html` 첫 화면 **연결 설정**에서 클라이언트 ID와 시트 ID를 입력 → **Google 로그인 후 연결 테스트** → **저장 후 로그인·새로고침**. 로그인 토큰은 탭을 닫으면 사라집니다.
4. 이후 **새로고침** 버튼으로 시트 최신 값을 반영합니다.

B. Apps Script 공유 키(내부 시험용)는 키를 아는 사람이 모두 읽을 수 있어 운영에는 권장하지 않습니다(`apps-script/README.md`).

## 상시 자동 연동 (Google 로그인 방식)

- 처음 한 번 로그인·동의하면, 다음 방문에는 로그인 상태를 자동으로 재확인해 데이터를 불러옵니다(브라우저가 팝업을 허용하고 Google에 로그인된 상태면 클릭 없이, 아니면 [로그인 상태 재확인] 버튼 한 번).
- 열 때마다 최신 데이터를 조회하고, 열어 둔 동안 5분마다 변경을 확인합니다(변경이 있을 때만 화면 갱신). 화면에는 마지막 정상 동기화 시각과 현재 상태가 표시됩니다.
- 모든 탭을 한 번의 요청으로 읽고 검사를 통과한 뒤 한꺼번에 교체하므로 일부만 새 값으로 바뀌지 않습니다. KPI 탭과 판매 원문 합계가 어긋나면 새 값을 적용하지 않고 이전 스냅샷을 유지합니다.
- 연결 실패(네트워크·서버)는 마지막 조회값을 "이전 데이터"로 명확히 표시합니다. 로그인 만료는 재로그인을 안내하고 일정 시간(15분) 안에 재로그인하지 않으면 데이터를 화면에서 지웁니다. 접근 권한 취소(403)와 로그아웃은 즉시 데이터를 지웁니다. 조회한 데이터는 메모리에만 있고 브라우저 저장소에 쓰지 않습니다.
- 시트에 탭이 없거나 열 구조가 바뀌면 경고를 띄우고 해당 카드는 0으로 대체하지 않고 표시하지 않습니다.

**반드시 확인:** 스프레드시트의 일반 액세스가 "링크가 있는 모든 사용자"이면 로그인 없이도 누구나 읽을 수 있어 위 접근 통제가 무효입니다. 반드시 "제한됨"으로 두고, `로그인 없이 시트가 읽히는지`를 정기적으로 점검하세요(익명 요청이 모두 실패해야 정상).

## 보안 모델

- 스프레드시트는 비공개로 유지됩니다. A 방식은 로그인한 직원 계정의 권한(spreadsheets.readonly)으로 Sheets API를 직접 호출하므로 시트를 공유받지 않은 사람은 읽을 수 없습니다.
- 공유 키가 없습니다(B 방식 제외). 클라이언트 ID·시트 ID·토큰은 저장소·HTML에 포함되지 않고 각 브라우저(localStorage / 탭 단위 sessionStorage)에만 있습니다.
- 연결에 실패하거나 키가 없으면 어떤 수치도 표시하지 않고 "연결 대기"로 둡니다. 임의 샘플 숫자를 만들지 않습니다.
- 업무 트래커의 업무 기록(localStorage `netform.b2b.tracker.v1`)과 KPI 연결 정보(`netform.b2b.sheetlink.v1`)는 분리되어 있으며 KPI 모듈은 업무 기록을 읽거나 쓰지 않습니다.

## 데이터 탭 구조 (요약)

웹앱이 읽는 스프레드시트에는 `1.통합KPI`, `2.시공사마스터`, `3.이카운트판매원문`, `4.메인자재구매현황`, `5.POUR공고낙찰`, `5b.POUR반영공고`, `6.타사공법낙찰`, `7.기술자문문의`, `7b.플랫폼가입현황`, `8.컨설팅요청`, `8b.컨설팅발행이력`, `9.샘플카탈로그요청`, `10.공법설명회이력`, `11.기타문의답변`, `12.거래처연결검토`, `13.데이터검증변경이력`, `14.판매원문차이검증`, `15.마스터대조`, `16.L2L3전환`, `16b.L2L3시공사별`, `16c.L2L3판정집계`, `16d.L2L3검토이력`, `17.장기무활동`, `18.선행지표요약`, `19.업체명정규화` 탭이 있어야 합니다. 탭이 없으면 해당 카드는 "탭 없음"으로 안내합니다.

## 로컬 테스트

```bash
node tools/mock-sheet-server.cjs 5180 <탭데이터.json> <키>
node tools/mock-appsscript-redirect.cjs 5183 <탭데이터.json> <키>
```

`<탭데이터.json>`은 `{ meta:{tabs:{…}}, tabs:{ 탭이름:{ header:[…], rows:[[…]] } } }` 형식이며 저장소에 포함하지 않습니다.
